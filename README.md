## 💡 About the Project

ShopOpti is a smart shopping assistant that helps users find the best combination of products within their budget.

It uses three core algorithms:

- 🎒 **0/1 Knapsack** — selects the best product combination within the budget.
- 🔢 **Sorting** — organizes products by price, rating, discount, or utility.
- 🔍 **Binary Search** — quickly searches sorted product data.

## 🧠 DAA Algorithms

| Algorithm | Purpose | Complexity |
|---|---|---|
| 0/1 Knapsack | Best product combination | O(n × B) |
| Sorting | Organize products | O(n log n) |
| Binary Search | Fast product search | O(log n) |
